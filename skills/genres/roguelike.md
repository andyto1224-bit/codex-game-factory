# Roguelike 规则

- 局内随机统一 `SeededRNG`，禁止 `Math.random()` 决定掉落/战斗；存档记录 seed、RNG 状态或可回放输入和调用序号。
- 权重三选一池：过滤未解锁/互斥/满级条目，再按正权重无放回抽取；不足三个时明确 fallback，不复制同一选项。边界权重和空池须有单测。
- 局内存档（地图、HP、技能、seed、当前进度）与局外存档（解锁、货币、设置）分离命名空间和版本；迁移失败回退安全默认，结算奖励幂等。
- 1000 seeds 完整模拟记录通关率、流派覆盖、死亡层数、极端组合与无选项次数；稀有奖励不能造成稳定软锁。保存失败 seed 可一键复现。
