# 游戏设计理论落地

- 核心循环控制在 3–5 分钟：观察 → 一个明确动作 → 即时反馈 → 小目标完成 → 下一次决策；首个有效操作 5 秒内发生。
- 难度按分段曲线增长：先建立成功，再增加一个维度（速度/目标/约束），不要同步拉高全部变量。写成可测函数，例如 `min(cap, base + floor(round/3)*step)`。
- 正反馈奖励技巧并提供短高潮；负反馈保留可恢复空间，避免领先无限滚雪球/失败连续惩罚。每 20–40 秒安排一次可理解的小回报。
- 策略玩法给至少两个有意义选项，随机不可覆盖全部技巧；记录 seed。动作玩法输入可预期，死亡原因可读。
- GDD 必须给出目标胜率、局长分位数、失败原因分布和复活收益上限；用模拟或确定性测试验证，再用白盒人审校正。
- 商业化插入循环边界，不阻断首局理解。复活恢复有限资源，不无条件永久不败。
