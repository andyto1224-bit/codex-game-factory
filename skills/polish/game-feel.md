# 手感打磨

- GSAP 按压缩放：down 0.94 / 70ms，up 1 / 140ms；抬手/取消/失焦均复位；退出场景 killTweensOf，减少动画偏好时立即复位。
- 成功动作同时触发 80–220ms 粒子飞溅、短音和目标 squash；粒子预热对象池，寿命结束回收，禁止每帧 new 大量对象。
- Combo 飘字按连击提高尺寸与色彩但限制屏内数量；120ms 出现、400ms 上浮淡出，合并同帧爆发。输入队列不依赖 Tween 回调确定玩法结果。
- 微震屏幅度 2–4 设计像素、时长 80–120ms，仅震表现容器，不移动 UI 或改变碰撞。减弱动画时禁用。
- WebAudio 首次 `pointerdown/touchstart` 解锁；连击频率例如 440Hz × 2^(min(combo,12)/12)，限制音量与并发，后台静音，返回前台尊重用户 mute。不在无交互时强制自动播放。
- 正反馈先确认输入再放大结果；失败给 150ms 可辨识反馈，避免持续红闪。关键事件去重，音画使用同一表现事件。

验收：连续快速输入无叠加失控、10 次开关场景无悬挂 Tween、后台无声音、reduced-motion 生效。模板只示范轻量反馈，项目按视觉契约补齐粒子/Combo 等完整表现。
